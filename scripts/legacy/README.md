# Legacy Scripts

`scripts/legacy/` は、公式 Blender MCP へ切り替える前の旧独自構成を前提にした補助スクリプト置き場です。

これらは主経路ではありません。
比較、移行差分確認、転用検討のために保持しています。

現行の導入と検証は、repo 直下の `scripts/install_official_blender_mcp*.ps1`、`scripts/install_official_blender_mcp_server*.ps1`、`scripts/register_official_blender_mcp_in_codex.ps1`、`scripts/enable_official_blender_mcp_addon.ps1` を優先してください。
